# محاسب سوفت — MuhasibSoft

تطبيق محاسبة أندرويد أصلي باستخدام Kotlin وJetpack Compose وMaterial 3، مع قاعدة بيانات محلية Room.

## الموجود حالياً
- واجهة عربية للوحة المعلومات.
- ربط شاشة الملخص بقاعدة بيانات Room محلية.
- نماذج البيانات الأساسية للأصناف والمبيعات والمشتريات والحسابات والمخزون.
- حقن تبعيات Hilt.
- إعداد GitHub Actions لبناء APK ورفعه كـ artifact.

## التقنية
- Kotlin / Android SDK 34 / Java 17
- Jetpack Compose + Material 3
- Room + Coroutines / Flow
- Hilt
- الحد الأدنى Android 7.0 (API 24)

## البناء السحابي
من تبويب Actions شغّل MuhasibSoft Android Build أو ادفع تحديثاً إلى الفرع main.
عند نجاح المهمة، افتح تشغيل البناء ثم نزّل artifact باسم MuhasibSoft-APK.

> ملاحظة: لا يُعتبر التطبيق منتجاً نهائياً حتى تكتمل شاشات الإدخال والتعديل والمبيعات والمشتريات والقيود والتقارير وتُختبر جميعها على جهاز فعلي.
